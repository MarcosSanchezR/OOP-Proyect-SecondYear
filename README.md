# OOP_Project2025

## OverView
This project was developed as part of the Object-Oriented Programming course in the second degree year at Universidad Politécnica de Madrid. It implement a set management system supporting creation, reading, and deletion of users to organize tennis matches between players using Java, also I did programme sql repositories but I didn't connect them into the DependencyInjector. For the frontend of the system I use a simple GUI in JavaFX.

## Feature

- Create and manage matches.
- Create, delete and read user, courts and matches.
- A Java application designed with a four-layer architecture (View, Controller, Repository, Model), applying separation of concerns and modular design principles.

### Tech Stack
- **Language**: Java.
- **Build Tool**: Maven.
## Setup and Execution
  1.Clone this repository.
   ```git clone https://github.com/MarcosSanchezR/Proyecto-Poo-segundo.git ```
  2.Run the project in your IDE and run the project from maven using: mvn clean javafx:run.
